# Forge Automotive — Luxury Atelier Website Recreation

> Pixel-precise, high-fidelity recreation of [Forge Automotive](https://forgeautomotive.co.uk/) — a bespoke automotive atelier specializing in one-off styling, performance engineering, and craftsmanship for Land Rover Defender, Mercedes-AMG G63, Range Rover, Lamborghini Urus, Audi RS, and Porsche 911 builds.

---

## Features & Highlights

- **Next.js 15 (App Router):** Pre-rendered with 100% Static Site Generation (SSG) across all 21 routes.
- **Production Typography:** Authentic font definitions for **PPEditorialNew** (Light, Ultralight, Ultralight Italic) and **GeistSans** (Variable).
- **Interactive Mouse Trail:** Interactive snapshot pop-up canvas over the atelier philosophy statement (*"We don’t modify vehicles We build them for you"*).
- **Cinematic Hero:** Luxury 5-car reflective studio lineup with staged typography reveals.
- **3-Pillar Approach Slider:** Synchronized 6-second auto-advancing progress line across *Identity*, *Insight*, and *Cohesion*.
- **Continuous Marquee:** Seamless looping marquee of 14 luxury automotive marques.
- **6 Bespoke Services:** Interactive showcase for *Bodystyling*, *Interior*, *Wheels*, *Lighting*, *Exhaust*, and *Protection*.
- **Previous Builds Archive & Dynamic Showcases:** Full archive (`/builds`) and individual showcases (`/builds/[slug]`) for `#FA001` through `#FA010`.
- **Available Stock Inventory:** Live acquisition opportunities with spec sheets and direct enquiry forms (`/stock`, `/stock/fa003`).
- **Commissions Hub:** Interactive specification request form and studio locations in Yorkshire and the North West (`/contact`).
- **Full-Screen Oxblood Menu:** Watermark logo with mouse parallax, 3D character roll-down link transitions, and attribution credits.
- **Smooth Scrolling:** Powered by Lenis with automatic suspension when navigation overlays are active.

## Getting Started

### Prerequisites
- Node.js 18.18+ or 20+
- npm, pnpm, or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Opivamp/2D-animated-website.git
cd 2D-animated-website

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```
